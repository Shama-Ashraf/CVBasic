# Basic Computer Vision Operations on Images

This project demonstrates **basic computer vision (CV) operations** on images using Python and OpenCV. It is intended for beginners who want to learn how to manipulate and analyze images.

## Features

The project includes the following basic CV operations:

- Loading and displaying images
- Converting images to grayscale
- Resizing images
- Rotating images (90° clockwise)
- Edge detection using Canny
- Drawing shapes (rectangle, circle, line) on images


 
## Requirements

- Python 3.x  
- NumPy  
- OpenCV (`opencv-python`)  
- Matplotlib
